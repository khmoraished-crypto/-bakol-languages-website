# AI Media Lab | مختبر الإعلام الذكي

منصة ويب عربية (RTL) تجمع خمس أدوات للعمل الإعلامي في مساحة عمل واحدة:

| الأداة | المسار | ما تقدمه |
| --- | --- | --- |
| غرفة الأخبار الذكية | `/tools/newsroom` | مسودة خبر (عنوان، مقدمة، متن) مع فحص العناصر الستة وتنبيه عند النقص |
| المحرر الصحفي الذكي | `/tools/editor` | إعادة صياغة، اختصار، تدقيق لغوي، خمسة عناوين بديلة |
| استوديو الإنتاج الإعلامي | `/tools/studio` | سيناريو مقسّم إلى مشاهد بتوقيتات وزوايا تصوير وتعليق صوتي |
| مصمم البرامج التدريبية | `/tools/training` | أهداف ومحاور وأنشطة ومخرجات قابلة للقياس وجدول زمني وتقييم |
| مختبر الأفكار الإعلامية | `/tools/ideas` | أفكار حملات ومحتوى مصنفة حسب المنصة والجمهور والغرض |

كل نتيجة يمكن **تحريرها** مباشرة، و**نسخها**، و**حفظها كمسودة** في المتصفح (`/drafts`)، و**تصديرها PDF** أو Markdown.

## التقنيات

Next.js 15 (App Router) · TypeScript · Tailwind CSS 4 · مكونات shadcn/ui (Radix) · Framer Motion · Zod · Sonner · html2canvas-pro + jsPDF · خط IBM Plex Sans Arabic (مستضاف ذاتيًا).

## التشغيل محليًا

```bash
npm install
cp .env.example .env.local   # اختياري — لتفعيل الذكاء الاصطناعي
npm run dev                  # http://localhost:3000
```

أوامر أخرى:

```bash
npm run build && npm start   # نسخة إنتاج
npm run lint                 # ESLint
npm run typecheck            # TypeScript
```

يتطلب Node.js 18.18 أو أحدث.

## أوضاع التشغيل

- **الوضع التجريبي (افتراضي):** دون أي مفتاح، تعمل الأدوات بقوالب وقواعد تحريرية ثابتة (`src/lib/ai/demo`). تظهر كل نتيجة بشارة «نتيجة تجريبية» وتنبيه صريح بأنها **ليست مولّدة بالذكاء الاصطناعي**.
- **وضع الذكاء الاصطناعي:** عند ضبط متغيرات البيئة يُرسل الطلب إلى المزوّد من الخادم فقط، وتظهر النتيجة بشارة «مولّد بالذكاء الاصطناعي».

```env
AI_PROVIDER=anthropic        # أو openai
AI_API_KEY=...               # يُقرأ على الخادم فقط
AI_MODEL=                    # اختياري (الافتراضي: claude-sonnet-5-5 / gpt-4o-mini)
AI_BASE_URL=                 # اختياري لواجهة متوافقة مع OpenAI
AI_RATE_LIMIT_PER_MINUTE=20
```

## الأمان

- المفاتيح في متغيرات بيئة **دون** بادئة `NEXT_PUBLIC_`، وملفات المزوّد تستورد `server-only` فلا يمكن تضمينها في حزمة المتصفح.
- `/api/generate` يتحقق من المدخلات بـ Zod، ويحدّ حجم الطلب (32KB) وعدده لكل IP، ولا يعيد تفاصيل أخطاء المزوّد إلى العميل.
- `/api/status` يكشف فقط إن كان الذكاء الاصطناعي مفعّلًا.
- رؤوس أمان HTTP مضبوطة في `next.config.ts`.
- محدِّد المعدل في الذاكرة يناسب نسخة واحدة؛ في النشر متعدد النسخ استبدله بـ Redis/Upstash (`src/lib/ai/rate-limit.ts`).

## بنية المشروع

```
src/
├─ app/                    الصفحات ومسارات API
│  ├─ api/generate         التوليد (ذكاء اصطناعي أو تجريبي)
│  ├─ api/status           حالة الربط
│  ├─ tools/*              صفحات الأدوات الخمس
│  ├─ drafts, about        المسودات وعن المنصة
├─ components/
│  ├─ ui/                  مكونات shadcn/ui
│  ├─ layout/              الترويسة والتذييل والشعار
│  ├─ home/                أقسام الصفحة الرئيسية
│  ├─ tools/               مساحة العمل، لوحة النتائج، النماذج
│  └─ drafts/              قائمة المسودات
├─ hooks/                  التوليد، حفظ النماذج تلقائيًا، حالة الربط
└─ lib/
   ├─ ai/types.ts          مخططات المدخلات وصيغة المستند الموحدة
   ├─ ai/prompts.ts        تعليمات النماذج لكل أداة (خادم)
   ├─ ai/provider.ts       محوّل Anthropic / OpenAI (خادم)
   ├─ ai/demo/             محركات الوضع التجريبي
   ├─ drafts.ts            تخزين المسودات محليًا
   └─ export-pdf.ts        تصدير PDF يدعم العربية
```

### إضافة أداة جديدة

1. أضف المعرّف ومخطط المدخلات في `lib/ai/types.ts`.
2. أضف التعليمات في `lib/ai/prompts.ts` ومحركًا تجريبيًا في `lib/ai/demo/`.
3. أضف البيانات الوصفية في `lib/tools-config.ts`.
4. أنشئ نموذجًا يستخدم `ToolWorkspace` وصفحة في `app/tools/<id>`.

> ملاحظة: مسارات API تتطلب بيئة Node؛ لا يدعم المشروع التصدير الثابت (`next export`).
